# AirVerse Screen Share

**AirVerse Screen Share** is a simple, elegant tool that allows you to share your screen with others in real-time — no complicated setup required.

## 🌐 Overview

- Easily share your screen with a single link.
- View others’ shared screens directly in your browser.
- Perfect for lightweight, real-time collaboration, presentations, or support.

## 📸 Features

- Minimal, dark-themed UI
- Fast, secure screen sharing
- View-only mode with link-based access
- No account or login required

## 🛠 Tech Stack

- **Frontend:** Lightweight friendly web UI  
- **Desktop App:** Python-based with cross-platform potential  
- **Protocol:** MQTT for real-time communication  

## 🔒 Privacy

AirVerse Screen Share does **not** store or relay your screen through any central server. All data is shared peer-to-peer using secure channels.
